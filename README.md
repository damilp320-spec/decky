# Зеркало магазина плагинов Decky на GitHub

Официальный магазин Decky живёт на `plugins.deckbrew.xyz`, а сами плагины — на
`cdn.tzatzikiweeb.moe`. Если до этих адресов не достучаться, магазин на Steam Deck
крутит вечную загрузку или не ставит плагины.

Этот репозиторий раз в 6 часов сам скачивает официальный список плагинов и все
zip-архивы и раскладывает их на GitHub Pages. На Steam Deck нужно один раз вписать
один адрес — дальше магазин работает как обычно.

**Адрес для Decky** — тот, что выдал Vercel после деплоя прослойки (см. ниже):

```
https://<проект>.vercel.app/plugins
```

Напрямую адрес GitHub Pages (`https://damilp320-spec.github.io/decky/plugins`) в
Decky вписать нельзя: Decky запрашивает список из браузерного контекста Steam и
шлёт свой заголовок `X-Decky-Version`. Из-за нестандартного заголовка браузер
сначала делает preflight-запрос `OPTIONS`, а GitHub Pages отвечает на него `405`
без CORS-заголовков — список молча не грузится. Официальный стор на такой запрос
отвечает `access-control-allow-headers: x-decky-version`.

Поэтому список отдаёт крошечная функция в `api/plugins.js`: она берёт тот же JSON
с GitHub Pages и добавляет недостающие заголовки. Через неё идут только 82 КБ
списка — архивы плагинов качает питоновский бэкенд Decky напрямую с GitHub
Pages, и CORS там не применяется.

## Что включить один раз в репозитории

1. Влить эту ветку в `main` (по расписанию Actions запускаются только из `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. **Actions → «Обновить зеркало» → Run workflow.** Первый запуск качает ~320 МБ и
   занимает 5–15 минут, дальше работает только докачка изменившегося.
4. Открыть `https://damilp320-spec.github.io/decky/` в браузере — там статус зеркала
   и список плагинов.
5. Развернуть прослойку с CORS: [vercel.com](https://vercel.com) → войти через
   GitHub → **Add New → Project** → импортировать этот репозиторий → **Deploy**.
   Собирать нечего, деплой занимает меньше минуты, дальше он повторяется сам при
   каждом push. Адрес для Decky — `https://<проект>.vercel.app/plugins`.

## Что сделать на Steam Deck

1. Игровой режим → кнопка **⋯ (QAM)** → значок Decky (штекер) → **шестерёнка**
   (Settings).
2. Вкладка **General**, раздел **Beta** → **Store channel** → **Custom**.
3. В поле **Custom store URL** вписать адрес выше.
4. Вернуться в магазин Decky (значок магазина) — список должен загрузиться.

Установка и обновление плагинов дальше работают как обычно, включая кнопку
«Update all».

## Как это устроено

- `scripts/sync.py` берёт JSON официального стора, скачивает по последней версии
  каждого плагина и картинки карточек.
- Каждый архив проверяется по SHA-256: Decky при установке сверяет хеш
  (`backend/decky_loader/browser.py` в `decky-loader`), поэтому зеркало отдаёт
  файлы байт-в-байт, ничего не переупаковывая.
- В JSON у каждой версии проставляется поле `artifact` — если оно есть, Decky
  качает архив по нему, а не с официального CDN (`frontend/src/store.tsx`).
  `image_url` тоже переписывается на зеркало, чтобы картинки грузились.
- Всё складывается на GitHub Pages: и JSON, и архивы, и картинки — один домен,
  один адрес.
- Заодно копия архивов заливается в релиз `artifacts`. Если вдруг Pages будет
  отдавать архивы плохо, есть запасной адрес, где JSON тот же, а архивы идут с
  `github.com`:

  ```
  https://damilp320-spec.github.io/decky/plugins-gh
  ```

## Ограничения

- Зеркалится **последняя версия** каждого плагина. Прошлые версии остаются в
  релизе `artifacts` (ничего не удаляется), но в списке магазина не показываются.
  Нужно хранить больше — поменяй `KEEP_VERSIONS` в `.github/workflows/mirror.yml`.
- **Сортировка** в магазине не переключается: официальный стор сортирует на
  сервере, а статичный файл так не умеет. Список отдаётся по алфавиту, поиск по
  названию работает (он и так на стороне Decky).
- **Счётчик установок** не увеличивается: Decky шлёт POST на адрес магазина, а
  статичный хостинг его не принимает. На установку это не влияет — в логе просто
  появляется строчка об ошибке.
- Некоторые плагины при установке докачивают отдельные бинарники со своих
  адресов (обычно с `github.com`). Такие плагины перечислены на главной странице
  зеркала — если именно они не ставятся, дело не в зеркале.
- Если магазин не открывается совсем, плагин можно поставить вручную: на главной
  странице зеркала у каждого плагина есть ссылка на zip, её вставляют в
  Decky → Settings → Developer mode → Install Plugin from URL. Там качает бэкенд,
  так что CORS не мешает.
- Свежие версии появляются с задержкой до 6 часов. Нужно быстрее — запусти
  workflow вручную.

## Если что-то не работает

- **Магазин пустой или крутится загрузка** — открой адрес зеркала в браузере на
  деке (Firefox из Discover) или на телефоне. Не открывается — значит недоступен
  сам `github.io`, попробуй запасной адрес или другой канал в интернет.
- **Плагин скачивается, но не ставится** — почти всегда несовпадение SHA-256 или
  докачка бинарника. Логи: `journalctl -u plugin_loader -n 100` или
  `/home/deck/homebrew/services/plugin_loader.log`.
- **Плагина нет в списке** — посмотри раздел «Не зеркалировалось» на главной
  странице зеркала и `status.json`.
- **Вернуть официальный магазин** — Store channel → Default.
